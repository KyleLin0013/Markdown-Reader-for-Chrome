# 把注意力，留给内容。

在文件列表中选择一份文档，沿着目录找到章节。阅读器会记住你使用的配色、字号和侧栏标签。

## 有层次的文字

**重点**可以很清楚，*补充说明*可以轻一点。行内代码如 `README.md` 会保留独立的样式。

> 好的排版，让长文也有清楚的方向。

## 简洁的表格

| 位置 | 用途 |
| --- | --- |
| 文件 | 切换同文件夹中的文档 |
| 目录 | 跳转当前文档的章节 |
| Aa 阅读设置 | 调整字号、版心、明暗和配色 |

## 一段代码

```markdown
[阅读清单](阅读清单.md)
[跨文件跳转](章节/使用指南.md#中文锚点)
```
