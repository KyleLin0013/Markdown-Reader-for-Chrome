这份文档用于验证跨文件定位。目标章节安排在页面中部，点击链接后应直接看到标题，而不是停留在这里。

## 关于 MD Reader

MD Reader 在原文件地址上呈现 Markdown，文档中的相对链接沿用原来的路径。

### 阅读节奏

让文字有呼吸的空间。宽度适中的正文能够减少长距离扫视，清楚的标题层级让长文更容易找到方向。

阅读器在文档排版完成后读取地址中的章节信息，重新找到目标位置。中文会先进行 URL 解码，重复标题使用不同的后缀。

### 关于链接

链接可以连接同一份文档中的章节，也可以连接其他文档。相对路径从当前文件所在目录计算，浏览器会处理上一级目录和中文文件名。

```markdown
[返回](../开始阅读.md)
[本页章节](#中文锚点)
```

### 一个小约定

英文标题会转换为小写，单词之间使用短横线。比如 `Hello World` 对应 `#hello-world`。中文会保留，而标点会根据 GitHub 的标题规则处理。

如果你希望一个章节的地址长期保持不变，可以使用自定义标题标识，或写一个 HTML 锚点。

## 安静的末尾

你可以使用浏览器后退回到前一份文档，也可以继续通过目录浏览。这些操作都沿用浏览器自己的历史记录。

### 关于图片

图片可能比文字加载得更晚。当图片改变页面高度时，阅读器会在短时间内修正目标位置；你主动滚动后，修正会立即停止。

### 关于主题

在「Aa 阅读设置」里可以选择跟随系统、浅色或深色。下一份文档会沿用你的字号、版心和配色设置。

### 关于源文

点击工具栏的 `</>` 可查看原始 Markdown，再点击即可返回阅读状态。源文视图只读，不会修改你的文件。

### 关于打印

打印会去掉目录和工具栏，保留文档正文。使用 Chrome 的打印对话框可以保存为 PDF。

### 继续阅读

让文档之间的路径保持自然，也让每一段内容都有可抵达的位置。
