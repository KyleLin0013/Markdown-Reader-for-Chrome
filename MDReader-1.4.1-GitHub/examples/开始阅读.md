# 留一点空间，给阅读。

一个轻巧的 Markdown 阅读器，让文档之间的每一次跳转，都抵达你想读的地方。

> MD Reader  
> 本地打开，安静阅读。无需账号，也无需上传文档。

## 从这里开始

把这份文件拖入 Chrome，就可以阅读。左侧目录会跟随你的阅读位置，顶部的「Aa 阅读设置」可以调整字号、版心和配色。

**试一次跨文档跳转：** [直接前往使用指南的「中文锚点」章节](章节/使用指南.md#中文锚点)。打开后应停在目标标题，并以主题色提示位置。

## 排版，为内容让路

阅读一份好的文档，不该花太多力气。合适的行宽、清晰的层级、自然的留白，让目光有地方停留。

### 有条理的清单

- 支持中文、英文和混合标题。
- 保留相对路径，不需要修改已有 Markdown 文件。
- 目录自动生成，重复标题也有独立地址。
- 所有解析与渲染都在浏览器本地完成。

### 一点代码

```markdown
[跳到另一份文档的章节](章节/使用指南.md#中文锚点)

## 自定义标题 {#my-section}
```

### 记录阅读进度

- [x] 打开这份文档
- [ ] 点击链接，跳到另一份文档的指定章节
- [ ] 试试深色主题

## 保持简单

你可以在 MD Reader 中查看源文，或通过打印保存为 PDF。

Markdown 中引用的在线图片会按原地址加载；如果希望完全离线阅读，请使用本地图片。

愿每一次阅读，都有所收获。
